# Tower Bugs: Frog Defense

A grid-based tower-defense game in the Dungeon Dice Frogs universe.

## Prototype goals
- Player-built maze using grid blocks
- Shortest-path frog navigation
- Placement validation so the Tower can never be fully blocked
- Wave combat with a skippable 10-second intermission
- In-level Coins for bugs, blocks, and temporary upgrades
- Persistent Bug Bucks awarded for completing levels
- Tiered frogs, bugs, elements, bosses, destructible defenses, and health bars

The first Android prototype is being built as a lightweight custom-view game so the core mechanics can be tested before final art assets are added.
